# ⚡ Shaz Mohamed (@callmeshazzam) — Official Creator Portfolio & Media Kit

A modern, high-conversion creator portfolio and interactive brand media kit engineered for **Shaz Mohamed (@callmeshazzam)** — digital tech creator, TEDx speaker, and storyteller known for his signature *"Tea × Tech × Sarcasm"* brand identity.

🌐 **Live Demo:** [https://shazzam-portfolio.vercel.app/](https://shazzam-portfolio.vercel.app/)

---

## 🚀 Key Highlights & Features

- **Cyber-Minimalist Dark UI:** High-contrast aesthetic with neon accents (#00FF66), glassmorphism, and responsive layout across mobile and desktop.
- **Creator Metrics & Media Kit:** High-impact stat counters highlighting reach:
  - **2.0M+** Instagram Followers
  - **2.6M+** YouTube Subscribers
  - **1.3B+** Lifetime Cross-Platform Views
  - **5.8%** Engagement Rate
- **Interactive Bento Grid:** Spotlights signature series such as *“CHAi with Tech”*, *“Mobile Kadhakal & Unboxings”*, and lifestyle reels.
- **Video & Content Showcase:** Curated short-form vertical reels (9:16) and long-form tech reviews with view counts and direct platform links.
- **Brand Collaboration Flow:** Dedicated media kit sections featuring audience demographics, brand trust badges, and an interactive collaboration booking terminal.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment & Hosting:** [Vercel](https://vercel.com/)
- **Version Control:** Git & GitHub
